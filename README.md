# 미식플래너 (MisikPlanner) 🍽️

> **내향인을 위한 미각 데이터 기반 UI 매칭 및 AI 미식 다이어리 SPA 웹 애플리케이션**

> ⚠️ **안내:** 본 프로젝트는 UI 인터랙션 및 API 바인딩 시연용 버전입니다.

---

## 📁 폴더 구조 & 아키텍처
**SPA(Single Page Application) 퍼블리싱 구조** — 단일 HTML 내에서 Vanilla JS와 DOM 제어를 통해 매끄러운 App-like 화면 전환을 구현했습니다.

---

## 🎯 UI/UX 디자인 & 퍼블리싱 컨셉

내향적인 사용자에게 '함께 식사'는 큰 인지적 부담입니다. 미식플래너는 성향이 맞는 미식가와 부담 없이 매칭되어 최상의 미식 경험을 소비할 수 있도록 **직관적인 모드 분리 UI와 데이터 시각화**를 구현했습니다.

- **침묵 모드 vs 담소 모드**: UI 선택에 따라 톤앤매너와 방 목록이 동적으로 분기되는 인터페이스
- **실명 및 평판 시각화**: 정가 준수 배지 및 Clean Index 게이지 마크업으로 신뢰도 가시화
- **6축 미각 레이아웃**: 육각형 레이더 차트 기반의 직관적인 데이터 시각화 UI 제공

---

## 💎 핵심 차별점 (카카오 오픈채팅 대비 UI/UX 해결)

| 페인 포인트 | 미식플레너의 UI/UX 해결 방식 |
|---|---|
| 호스트의 가격 사기 | **정가 준수 약속 (Price Pact) 배지 컴포넌트** 마크업 |
| 노쇼 / 잠수 | **예약 사진 필수 업로드 UI** + 실명 평판 레이아웃 |
| 분위기 미스매치 | **침묵 / 담소 모드 탭 분리** 인터페이스 |
| 모르는 사람의 위험 | **호스트 배지 / Clean Index 시각화** |
| 신고 기능 없음 | **4종 사유 모달(Modal) 신고 시스템** UI 구현 |

## ✨ 주요 UI 컴포넌트 및 기능 구현 (Core Features)

### 1. 로딩 스플래시 & 오버레이
- SVG 애니메이션 기반의 냄비 김 연출 및 브랜드 로고 페이드인 오버레이

### 2. 홈 대시보드 (반응형 SPA)
- **원형 퀵 메뉴 컴포넌트**: 오픈채팅 · AI 미식투어 · 미식기록 3종 렌더링
- **풀카드 오토 슬라이더**: 미쉐린 스타 및 1인 세팅 업장 카러셀(Carousel) 슬라이더 구현
- **품격 약속 카드 UI**: 정가 준수 안내 인라인 컴포넌트

### 3. 인증 인터페이스 (Auth UI)
- Firebase Auth 및 소셜 로그인(구글/카카오/네이버) UI 모달 구현

### 4. 미식 매칭 인터랙션
- Canvas/CSS 애니메이션 기반 진행률 원형 게이지 (55% → 92%)
- 침묵 모드 / 담소 모드 탭 토글 UI

### 5. 오픈채팅 및 노쇼 방지 뷰
- 호스트 평판 배지 갤러리 및 마감된 방 비활성화 스타일링
- 예약 사진(캐치테이블/네이버예약) 상단 고정 배너 마크업
- 드롭다운 신고 모달 UI 컴포넌트

### 6. AI 미식투어 (Gemini API 바인딩)
- **Gemini API 연동**: 사용자 미각 프로필 데이터 기반 맞춤형 식당 추천 바인딩
- **MATCH 점수 & 차트**: 골드 그라데이션 차트 컴포넌트 및 빠른 질문 칩(Chip) UI

### 7. 미식 기록 & Gourmet Passport (미식 여권)
- **Web Speech API(STT)**: 음성 녹음 ➔ 실시간 텍스트 변환 UI 인터랙션
- **6축 미각 selector**: 단/짠/매/감/산/쓴 5단계 선택형 평가 버튼 마크업
- **육각형 레이더 차트**: Canvas 기반 사용자 미각 프로필 시각화
- **여권 테마 개인화**: CSS Variables 변경을 통한 5종 컬러 테마 바인딩
